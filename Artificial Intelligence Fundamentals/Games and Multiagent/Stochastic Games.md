# Stochastic Games

In addition to MAX and MIN nodes, **chance nodes** model all the possible outcomes of probabilistic events.

Extends [[Minimax]] by computing the value of a chance node as the **expected value** across all the possible probabilistic outcomes - i.e. maximum expected utility, see [[Probability and Decision Theory]].

Related: [[Monte-Carlo Tree Search]], [[Environments]].
