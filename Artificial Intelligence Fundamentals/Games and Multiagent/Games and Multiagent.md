# Games and Multiagent

Search when someone else is also choosing.

- [[Adversarial Search]] - two-player zero-sum games, the game tree.
- [[Minimax]] - the optimal strategy against perfect play.
- [[Alpha-Beta Pruning]] - the same answer, fewer nodes.
- [[Heuristic Game Search]] - cut-offs, the horizon effect.
- [[Monte-Carlo Tree Search]] - when there is no good evaluation function.
- [[Stochastic Games]] - chance nodes.
- [[Multiagent Systems]] - coordination, concurrency, conventions.
- [[Game Theory]] - normal form games, strategies, equilibria.
- [[Social Welfare]] - Pareto, utilitarian, egalitarian.
