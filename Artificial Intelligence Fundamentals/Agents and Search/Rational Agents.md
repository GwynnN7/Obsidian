# Rational Agents

A **rational agent** selects the action that maximizes a specified **performance measure**.

- Rationality is **not** omniscience, clairvoyance, or guaranteed success. It is doing the best you can with what you perceive.
- An **agent** is an entity capable of action, using **sensors** to perceive the environment and **actuators** to intervene.
- The **agent function** $f$ maps the entire history of percepts $P$ to a set of possible actions $A$.
- **Agent architecture** (actuators + sensors) + agent function = the agent.

## PEAS

A structured methodology for specifying an agent:

| | |
|---|---|
| **P** | Performance measure |
| **E** | Environment |
| **A** | Actuators |
| **S** | Sensors |
