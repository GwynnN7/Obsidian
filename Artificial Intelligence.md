## How these notes are organized

- One folder per subject, with a hub note at the top named like the subject.
- Inside, one folder per topic, each with its own hub note (MOC).
- One note per concept, linked with wikilinks; if something is said twice, it is a link, not a copy.
- `To Do` folders hold stubs for material not covered yet, so links never break.
