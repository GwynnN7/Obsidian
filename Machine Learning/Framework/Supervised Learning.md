# Supervised Learning

Learn an input-output mapping from labeled examples $(x,d)$, where $d=f(x)+\text{noise}$ is given by the teacher.

- Main tasks: [[Classification]] and [[Regression]].
- Training picks a hypothesis out of a [[Hypothesis Space and Inductive Bias|hypothesis space]] $H$ by minimizing an error on the training data ([[Generalization and Risk|empirical risk]]).
- Terminology from statistics: inputs = independent variables, outputs = dependent variables / responses.

Related: [[ML Framework]], [[Semi-Supervised Learning]].
